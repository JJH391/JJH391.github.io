# 서버 권위 게임인데도 웹소켓 메시지에 정답이 실려 있던 문제

- **한 줄 요약**: "정답은 서버에만 있다"고 생각했는데, 화면을 그리려고 보내던 데이터(기억력 게임 불빛 순서, 모스 부호 숫자)가 사실상 정답이었던 것
- **무엇이 있었나**:
  1. 친구가 AI와 개발자 도구로 웹소켓 메시지를 보고 정답을 알아냄.
  2. 서버가 보내는 메시지 종류(`lock`, `view` 등)를 하나씩 확인.
  3. 자물쇠 창을 열 때 보내는 `params`에 놀이공원 기억력 게임의 불빛 순서 전체(`params: { L_simon: { seq } }`)가 들어 있었고, 이것이 곧 정답.
  4. 폐병원 모스 전등 화면은 숫자(`digits`)를 보내고 브라우저가 깜빡임으로 바꾸고 있었음 → 해독 단계를 건너뛸 수 있음.
- **원인**: "화면에 그릴 재료"와 "정답"을 구분하지 않고 렌더링에 편한 형태로 보냄.
- **해결/결론**:
  - 기억력 게임: 불빛은 "보기"를 누를 때만 서버가 `setTimeout`으로 하나씩 보내고, 정답은 불빛 색이 아니라 별도 안내판의 "색 → 기호 버튼" 표(판마다 바뀜)와 합쳐야 나오게 변경.
  - 모스 부호: 숫자 대신 깜빡임 시간표(`on: [[시작, 끝], ...]`)만 전송.
  - 재발 방지 단위 테스트: 맵마다 200판, 자물쇠 `params`를 영숫자만 남겨 이어 붙인 문자열에 정답이 포함되면 실패.
- **코드/명령어**:

```js
// 단위 테스트 (발췌)
const flat = (x) => JSON.stringify(x ?? null).replace(/[^0-9A-Za-z]/g, '');
for (const [id, answer] of Object.entries(P.answers)) {
  if (!LOCKS[id] || String(answer).length < 4) continue;
  assert.ok(!flat(P.params[id]).includes(String(answer)), `맵 ${m} ${id}: 자물쇠 정보에 정답이 들어 있음`);
}
```
