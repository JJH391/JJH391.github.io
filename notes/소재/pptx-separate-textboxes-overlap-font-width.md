# 글을 줄마다 다른 글상자로 넣었더니 파워포인트에서 글자가 겹쳤다 (글꼴 폭 차이)

- **한 줄 요약**: 원래 글꼴(Noto Sans KR) 기준 위치에 글상자를 따로따로 놓았는데, 파워포인트의 맑은 고딕에서 줄이 하나 더 생겨 아래 글과 겹친 것
- **무엇이 있었나**:
  1. 위 방식으로 만든 PPTX를 파워포인트에서 열었더니 7번 장의 카드 안 글이 겹쳤다.
  2. 카드 안의 태그·제목·본문이 각각 고정 위치의 글상자였다.
- **에러/로그 원문**: 없음
- **원인**: 글꼴이 바뀌면 한 줄에 들어가는 글자 수가 달라진다. 독립된 글상자는 위 상자가 길어져도 밀려 내려가지 않는다.
- **해결/결론**:
  - 같은 부모(카드) 안에서 연달아 나오는 글은 **하나의 글상자**로 합치고, 각 문단의 `space_before`를 원래 요소 사이 간격(px × 0.5pt)으로 넣었다.
  - 글상자는 95개에서 45개로 줄었다.
  - 글꼴이 6% 넓다고 가정한(letter-spacing +0.06em) 미리보기로도 겹침이 없는지 확인했다.
  - 파워포인트에서 해결된 것을 확인했다.
- **코드/명령어**:
  ```python
  for m in members:                      # 같은 부모의 연속된 글 요소
      p = tf.add_paragraph()
      if prev is not None:
          gap = m['r'][1] - (prev['r'][1] + prev['r'][3])
          p.space_before = Pt(max(0, gap) * 0.5)
  ```
