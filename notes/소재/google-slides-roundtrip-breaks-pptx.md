# 구글 슬라이드에서 열었다 저장한 PPTX는 파워포인트에서 다시 깨진다

- **한 줄 요약**: PPTX를 구글 슬라이드에서 열고 다시 PPTX로 받으면, 고정 줄 간격이 "배수"로 바뀌고 표 크기가 망가져 파워포인트에서 글이 겹친 것
- **무엇이 있었나**:
  1. 파워포인트에서 정상이던 PPTX를 구글 슬라이드에서 열었다가 PPTX로 다시 내려받았다.
  2. 파워포인트에서 열었더니 배치가 다시 이상해졌다.
  3. python-pptx로 두 파일을 비교했다. 글자와 발표자 노트는 한 글자도 다르지 않았다.
- **에러/로그 원문**: 비교 결과(일부)
  ```
  1 줄간격 글 3 [182753, 800100] → [1.19916, 1.04999]
  2 줄간격 글 8 [304800] → [1.5]
  6 위치/크기 비교 표 (128, 326, 1662, 326) → (128, 326, 472, 472)
  ```
- **원인**:
  - python-pptx의 `line_spacing`은 고정 간격이면 길이(EMU), 배수면 실수로 나온다. 위 결과처럼 **모든 글상자의 고정 간격이 배수로 바뀌었다.**
  - 6번 장 표는 가로 1662px짜리가 472×472로 바뀌었다.
- **해결/결론**:
  - 파워포인트에서 확인한 원본 PPTX로 되돌렸다.
  - 발표용 파일은 파워포인트(PPTX) 또는 PDF로만 다루고, 구글 슬라이드를 거친 파일은 쓰지 않기로 했다.
- **코드/명령어**:
  ```python
  la = [p.line_spacing for p in a_shape.text_frame.paragraphs]
  lb = [p.line_spacing for p in b_shape.text_frame.paragraphs]
  if la != lb: print('줄간격', la, '→', lb)
  ```
