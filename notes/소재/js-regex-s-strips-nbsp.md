# JavaScript 정규식 `\s`는 NBSP(U+00A0)까지 지운다

- **한 줄 요약**: 공백 정리를 `replace(/\s+/g,' ')`로 했더니 코드 예시의 `&nbsp;` 들여쓰기까지 사라진 것
- **무엇이 있었나**:
  1. HTML 슬라이드의 글을 뽑아 PPTX로 옮겼다.
  2. 코드 예시 둘째 줄은 `&#160;&#160;`(NBSP 두 개)로 들여쓰기가 돼 있었다.
  3. PPTX에서는 이 들여쓰기가 사라졌다.
- **에러/로그 원문**: 없음. 바꾼 뒤 추출 결과는 다음과 같다.
  ```
  ['{ "t": "lock", "id": "L_simon",', '\n', '\xa0\xa0"params": { "seq": [2, 0, 3, 1, 1, 2] } }']
  ```
- **원인**: JS 정규식의 `\s`는 일반 공백뿐 아니라 U+00A0(NBSP) 같은 유니코드 공백도 포함한다.
- **해결/결론**: 줄일 공백만 명시했다(`/[ \t\n\r]+/g`). 파이썬 쪽도 `strip()` 대신 `strip(' ')`를 써서 NBSP를 남겼다.
- **코드/명령어**:
  ```js
  // 전
  n.textContent.replace(/\s+/g, ' ')
  // 후
  n.textContent.replace(/[ \t\n\r]+/g, ' ')
  ```
