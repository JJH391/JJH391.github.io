화면 없는 환경에서 3D 렌더링을 해야 할 일이 있었습니다. Blender를 별도 설치 없이 파이썬 모듈로 깔아 헤드리스로 돌리는 방법을 확인했습니다.

## 설치와 버전 확인

```
pip install bpy
```

설치 후 `bpy.app.version_string`으로 확인한 버전은 `5.2.2 LTS`였습니다.

## 테스트 장면과 렌더 설정

박스와 아이코스피어로 로우폴리 캐릭터를 코드로 구성한 뒤, 다음 설정으로 렌더했습니다.

- 렌더 엔진: Cycles
- 디바이스: CPU
- 샘플: 64
- 디노이즈: 사용

## 렌더 시간 실측

1080×1080 해상도 한 장을 렌더하는 데 걸린 시간은 다음과 같았습니다.

```
real 2m25.567s
```

## 발광(emission) 재질이 하얗게 날아간 문제

발광(emission) 재질의 강도를 6/10으로 설정했을 때 색이 하얗게 날아가 보이지 않았습니다. emission 세기를 1.2와 0.9로 낮추고, View Transform의 look을 `AgX`에서 `AgX - Punchy`로 바꾸자 색이 다시 보였습니다.

원인은 강한 emission 값이 AgX 톤 매핑에서 흰색 쪽으로 압축되는 현상으로 추정되나, 공식 문서로 대조해서 확인하지는 않았습니다. "emission을 낮추고 look을 바꾸니 색이 돌아왔다"는 실측 결과만 확인된 상태입니다.

## 정리

- `pip install bpy`로 Blender 5.2.2 LTS를 파이썬 모듈로 설치할 수 있다.
- Cycles CPU, 64샘플, 디노이즈 조건에서 1080×1080 한 장을 렌더하는 데 약 2분 25초가 걸렸다.
- 1분 분량(약 1,800프레임)을 이 속도로 렌더하는 것은 시간상 불가능한 범위다.
- 발광 재질이 톤 매핑에서 하얗게 날아가는 경우, emission 세기를 낮추고 View Transform look을 바꾸는 방법으로 대응할 수 있었다.
