HTML 슬라이드 안의 글을 뽑아서 다른 형식으로 옮기는 작업을 하고 있었습니다. 그 과정에서 텍스트에 들어 있는 공백을 정리하려고 `replace(/\s+/g, ' ')`를 썼는데, 옮긴 결과를 보니 코드 예시의 들여쓰기가 사라져 있었습니다.

문제가 된 코드 예시는 둘째 줄이 `&#160;&#160;`, 즉 NBSP(줄바꿈 없는 공백, U+00A0) 두 개로 들여쓰기가 돼 있었습니다. 공백을 정리한 뒤 추출 결과를 보면 이렇게 나옵니다.

```
['{ "t": "lock", "id": "L_simon",', '\n', '\xa0\xa0"params": { "seq": [2, 0, 3, 1, 1, 2] } }']
```

보이는 것과 달리 들여쓰기가 들어 있어야 할 자리의 NBSP 두 개가 통째로 사라져 있었습니다.

## 원인: 정규식의 `\s`는 일반 공백만 가리키지 않는다

JavaScript 정규식에서 `\s`는 스페이스, 탭, 줄바꿈 같은 일반 공백 문자만 포함하는 게 아니라 유니코드 공백 문자도 포함합니다. U+00A0(NBSP)도 여기에 들어갑니다.

그래서 "줄바꿈이나 탭처럼 흩어진 공백을 한 칸으로 합치자"는 의도로 쓴 `/\s+/g`가, 의도적으로 넣어둔 NBSP 들여쓰기까지 같은 공백으로 보고 한 칸으로 줄여버렸습니다. 일반 공백과 NBSP를 구분하지 않고 "공백이면 다 공백"으로 처리한 것이 원인입니다.

## 해결: 줄일 공백 문자를 명시적으로 지정

`\s`로 뭉뚱그리는 대신, 줄이고 싶은 공백 문자만 문자 클래스로 적었습니다.

```js
// 전
n.textContent.replace(/\s+/g, ' ')

// 후
n.textContent.replace(/[ \t\n\r]+/g, ' ')
```

이렇게 하면 스페이스·탭·줄바꿈만 한 칸으로 합쳐지고, NBSP는 그대로 남습니다.

같은 문제가 파이썬 쪽에도 있어서, 양 끝 공백을 지우는 `strip()` 대신 지울 문자를 지정하는 `strip(' ')`를 썼습니다. 인자 없는 `strip()`도 NBSP 같은 공백 문자를 함께 지우기 때문입니다.

## 정리

- JavaScript 정규식의 `\s`는 일반 공백뿐 아니라 NBSP(U+00A0) 같은 유니코드 공백 문자도 포함한다
- 들여쓰기나 특정 간격을 의도적으로 NBSP로 넣어둔 텍스트에 `/\s+/g`를 그대로 쓰면 그 간격이 사라질 수 있다
- 줄이고 싶은 공백이 정해져 있다면 `\s` 대신 `[ \t\n\r]`처럼 문자 클래스를 직접 적어 범위를 좁히는 편이 안전하다
- 파이썬의 `strip()`도 인자가 없으면 같은 방식으로 NBSP까지 지운다는 점이 같이 걸렸다
