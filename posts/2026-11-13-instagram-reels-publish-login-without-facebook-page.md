인스타그램에 릴스를 자동으로 올리는 방법을 찾다가, 페이스북 페이지 연결이 필요한 줄 알았던 부분과 실제 요구사항이 달랐던 점을 확인했습니다. 공식 문서(Content Publishing) 기준으로 정리합니다.

## 두 가지 연동 방식

인스타그램 콘텐츠 게시 API는 연동 방식이 두 가지입니다.

- **Facebook Login**: 인스타그램 비즈니스 계정이 페이스북 페이지에 연결되어 있어야 함
- **Instagram Login**: 페이스북 페이지 연결이 필요 없음

릴스 자동 게시만 목적이면 Instagram Login 방식으로 페이스북 페이지 없이 진행할 수 있습니다. 필요한 권한은 `instagram_business_basic`, `instagram_business_content_publish`이고, API 호스트는 `graph.instagram.com`입니다.

## 게시 흐름

문서에 나온 릴스 게시 절차는 세 단계입니다.

1. `POST /<IG_ID>/media` — `media_type=REELS`, `video_url`을 담아 컨테이너를 생성
2. `GET /<컨테이너ID>?fields=status_code` — 1분 간격으로 상태를 확인 (문서는 5분 이내 완료를 권장)
3. `POST /<IG_ID>/media_publish` — 1단계에서 받은 `creation_id`로 실제 게시

## video_url이 공개 주소여야 하는 이유

1단계의 `video_url`은 로컬 파일 경로나 인증이 필요한 주소가 아니라, 누구나 접근할 수 있는 공개 URL이어야 합니다. 인스타그램 서버가 이 URL로 직접 영상을 내려받아 처리하기 때문입니다.

공개 주소를 돈 안 쓰고 만드는 방법 중 하나는 공개 GitHub 저장소 + GitHub Pages입니다. 저장소에 영상 파일을 올리면 `https://<아이디>.github.io/<저장소>/v/파일명.mp4` 형태의 공개 주소가 생기고, 게시가 끝난 뒤 파일을 지우면 주소도 함께 없어집니다.

## 게시 한도 문서 불일치

같은 Content Publishing 문서 안에서 하루 게시 한도 숫자가 다르게 적혀 있습니다.

| 위치 | 적힌 한도 |
| --- | --- |
| 일반 게시 한도 설명 | 24시간 100개 |
| 캐러셀 게시 설명 | 24시간 50개 |

문서 자체에 두 숫자가 혼재되어 있어, 어느 쪽이 실제 적용되는 값인지는 문서만으로는 확정할 수 없습니다.

## 토큰 갱신

액세스 토큰은 `GET https://graph.instagram.com/refresh_access_token?grant_type=ig_refresh_token&access_token=...`로 갱신합니다.

- 발급 후 24시간이 지나야 갱신 가능
- 갱신하면 60일짜리 토큰으로 연장

## 정리

- Instagram Login 방식은 릴스 게시에 페이스북 페이지 연결이 필요 없다.
- `media` → 상태 확인 → `media_publish` 3단계로 게시하고, `video_url`은 반드시 공개 접근 가능한 주소여야 한다.
- 문서상 게시 한도는 100개와 50개로 다르게 적혀 있어 확정할 수 없다.
- 액세스 토큰은 발급 24시간 후부터 갱신 가능하고, 갱신 시 60일 연장된다.
