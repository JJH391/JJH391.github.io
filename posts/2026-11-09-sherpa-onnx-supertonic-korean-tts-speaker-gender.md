비용 0원 조건으로 한국어를 지원하는 오프라인 TTS(Text-to-Speech)를 찾는 과정이 있었습니다.

## 무엇이 있었나

- Hugging Face와 Edge TTS 서버는 샌드박스 환경에서 접속이 안 됐습니다(응답 코드 000). GitHub 릴리스 다운로드는 가능했습니다.
- sherpa-onnx 저장소의 예제에서 `sherpa-onnx-supertonic-3-tts-int8-2026-05-11.tar.bz2`(GitHub 릴리스로 배포되는 모델)를 발견했습니다. 예제 주석에는 "31 languages, e.g., en, ko"와 "10 speakers, sid 0-9"라고 적혀 있었습니다.

## 화자 번호의 성별이 안 나와 있던 문제

모델에는 화자 번호(sid) 0~9가 있는데, 각 번호가 남성 목소리인지 여성 목소리인지 알려주는 정보가 따로 없었습니다.

## 측정 방법

같은 문장을 sid 0~9로 각각 합성한 뒤, 자기상관(autocorrelation) 방식으로 기본 주파수(F0, 목소리의 높낮이를 나타내는 값)를 측정했습니다.

```python
g = sherpa_onnx.GenerationConfig()
g.sid, g.num_steps, g.speed = sid, 10, 1.0
g.extra["lang"] = "ko"
audio = tts.generate(text, g)
```

## 측정 결과

같은 문장 기준으로 F0가 두 구간으로 나뉘었습니다.

| 화자 번호(sid) | 기본 주파수(F0) |
| --- | --- |
| 0~4 | 165~228Hz |
| 5~9 | 94~128Hz |

일반적으로 성인 여성의 기본 주파수가 성인 남성보다 높게 측정되는 경향이 있어, 이 구간 차이를 성별 구분의 근거로 썼습니다.

합성 시간은 약 2.7초 분량의 음성을 만드는 데 CPU 기준 2.7~3.7초가 걸렸습니다.

## 참고: 속도를 유지하면서 음높이만 바꾸기

측정 중에 음높이만 따로 조절해볼 때 쓴 ffmpeg 명령입니다.

```bash
# 속도는 유지하고 음높이만 올리기
ffmpeg -i in.wav -af "asetrate=44100*1.12,aresample=44100,atempo=0.89286" out.wav
```

## 라이선스

모델 폴더의 README에 따르면 코드는 MIT, 모델은 OpenRAIL-M 라이선스입니다.

## 정리

- sherpa-onnx + Supertonic 3 모델은 한국어를 지원하는 무료 오프라인 TTS다.
- 화자 번호(sid) 0~9의 성별이 공식적으로 공개돼 있지 않아, 기본 주파수(F0)를 실측해서 두 그룹으로 나눴다: sid 0~4(165~228Hz), sid 5~9(94~128Hz).
- 코드는 MIT, 모델은 OpenRAIL-M 라이선스다.
